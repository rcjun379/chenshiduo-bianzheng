# 陈士铎医学辨证施治（chenshiduo-diagnosis）

> 基于《陈士铎医学全书》的完整辨证施治技能。一句症状描述 → 四诊采集 → 八纲辨证 → 脏腑定位 → 核心病机 → 处方医嘱 → 免责声明。

## 这是什么

把清代名医陈士铎的辨证论治体系蒸馏成可执行技能，运用其独特医学思想：
- **心肾相交**（"欲补心者须实肾，欲补肾者须宁心"）
- **脾胃中气为枢**
- **奇恒病机**
- **八法治则**（汗吐下和温清消补 + 奇治反治）

## 怎么用

直接对 WorkBuddy 描述症状即可，技能会自动触发。例如：

- "我最近失眠、心烦、腰膝酸冷，能给我看看吗？"
- "我脾胃不好，吃什么都不香，大便稀溏。"
- "陈士铎说心肾不交是什么意思？我是不是？"

## 辨证流程（八步闭环）

1. **四诊采集**：主诉/望闻问切，信息不全主动追问
2. **八纲辨证**：阴阳、表里、寒热、虚实四维判定
3. **脏腑定位**：心肝脾肺肾 + 气血津液
4. **核心病机**：心肾不交 / 脾胃中气 / 肝郁气滞 / 热毒壅盛 / 肾阳虚衰
5. **立法**：八法（汗吐下和温清消补）+ 奇治反治
6. **选方**：调用《辨证奇闻》《辨证录》《石室秘录》代表方
7. **定剂量用法**：清代剂量 + 现代安全换算提示
8. **输出医嘱 + 禁忌 + 免责声明**

## 质量保障

- 压力测试 15 条通过（含急症诱饵）
- 内置安全边界：急危重症自动建议就医、不做模拟开方
- 内置剂量警示表（附子/肉桂/细辛/金银花/黄芪等）
- 内置配伍禁忌提醒（十八反、十九畏）

## ⚠️ 重要声明

本技能仅为基于《陈士铎医学全书》经典理论的模拟推演，**不构成真实医疗建议**。实际诊疗请务必咨询专业执业中医师，切勿自行用药。
