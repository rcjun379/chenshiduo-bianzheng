# 陈士铎医学辨证施治

> WorkBuddy Skill · 中医学术思维模拟器（严格学术推演模式）

## ⚠️ 安全声明

本 Skill **严格限定为中医学术推演模式**，所有输出仅供学习参考，**绝对不构成医疗建议、诊断意见或处方凭证**。

- 🚨 请勿根据本 Skill 的输出自行购买、煎煮或服用任何中药材
- 🚨 急危重症请立即拨打 120 或前往正规医院急诊

## 简介

基于《陈士铎医学全书》（清代名医陈士铎原著）蒸馏的辨证施治技能，融合心肾相交、脾胃中气、奇恒病机、八法治则

## 使用方式

将 `chenshiduo-diagnosis` 文件夹放入 `~/.workbuddy/skills/` 目录。在 WorkBuddy 对话中触发相应症状描述时自动调用。
